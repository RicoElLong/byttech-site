1. Общие положения

Настоящая политика составлена с учётом Федерального закона от 27.07.2006 № 152-ФЗ «О персональных данных». Она описывает обработку данных посетителей сайта «БытТех» по адресу ricoellong.github.io/byttech-site/ и будущих заявок на ремонт стиральных машин в Самаре. Оператор обеспечивает соблюдение прав и свобод посетителей при обработке их данных, в том числе защиту частной жизни.

2. Основные понятия

Персональные данные — сведения, относящиеся прямо или косвенно к определённому либо определяемому человеку. Пользователь — посетитель сайта БытТех. Оператор — лицо, определяющее цели, состав и способы обработки таких сведений; его реквизиты будут указаны в политике до включения формы.

Обработка включает сбор, запись, систематизацию, хранение, уточнение, использование, предоставление доступа, блокирование, удаление и уничтожение данных. Автоматизированная обработка выполняется с помощью вычислительной техники. Предоставление означает раскрытие определённому лицу или кругу лиц, а распространение — раскрытие неопределённому кругу лиц. Трансграничная передача — передача данных получателю на территории иностранного государства.

3. Цели и состав данных

После отдельного включения формы данные заявки будут использоваться только для ответа на обращение, уточнения поломки, предварительной оценки и согласования условий выезда и ремонта. Для этого посетитель указывает имя, телефон, марку машины, неисправность и, по желанию, комментарий. Также фиксируются время и версия согласия, номер заявки и необходимые технические сведения для защиты формы от автоматических запросов.

Не указывайте в комментарии паспортные или платёжные сведения, сведения о здоровье и другие данные, не нужные для ремонта. Согласие на заявку не охватывает рекламные рассылки и публикацию отзывов: для них нужны отдельные основания и решения посетителя.

4. Основание и действия с данными

Основанием обработки данных заявки служит отдельное согласие на обработку персональных данных. Галочка в форме не установлена заранее; без неё заявка не отправляется. Планируемые действия: получение, запись, систематизация, хранение, уточнение, использование для связи по заявке, блокирование и удаление данных с применением средств автоматизации и без них. При наличии иного законного основания отдельные действия могут продолжаться в пределах применимого законодательства.

5. Где хранятся заявки и кто получает доступ

При включении формы данные должны передаваться по HTTPS на сервер оператора в России и храниться в закрытой базе на этом сервере. Доступ к карточке заявки ограничивается авторизацией. Планируемый срок хранения — не более 30 дней после последнего обновления обращения, если до запуска не будет обоснован иной срок. Повторная заявка с тем же телефоном может обновить существующее обращение. Место размещения сервера, резервные копии и круг лиц с доступом должны быть подтверждены оператором до начала приёма заявок.

6. Уведомления и сторонние сервисы

В предусмотренной для формы схеме уведомление в Telegram содержит только случайный номер заявки и ссылку на защищённую карточку. Имя, телефон и комментарий через это уведомление не передаются. Переходя самостоятельно по ссылкам Telegram или MAX, посетитель взаимодействует с выбранной платформой по её правилам; данные формы не передаются туда самим переходом.

Сайт сейчас размещён на GitHub Pages. При открытии страницы провайдер хостинга может получать технические сведения о соединении. Перед включением формы оператор должен отдельно проверить фактических поставщиков услуг, место обработки и условия доступа к данным. Публикация отзывов клиентов возможна только по отдельному разрешению; сведения из заявки для этого не используются.

7. Технические данные и аналитика

На текущей версии GitHub Pages собственный сбор статистики посещений и кликов отключён. В коде подготовлен модуль для будущего собственного хостинга: при отдельном включении он будет хранить случайный ID браузера в localStorage и передавать тип события, путь страницы и назначение ссылки без параметров URL. Имя и телефон из формы в такую статистику не включаются; события старше 90 дней удаляются при следующей записи. До включения модуля оператор должен проверить основания обработки и обновить этот раздел с фактическим адресом сервера и условиями хранения.

Контакты из формы не записываются в localStorage или адрес страницы. Рекламные пиксели и рассылки по данным формы не подключены.

8. Защита и прекращение обработки

Для будущей формы предусмотрены HTTPS, ограничение частоты запросов и защита от автоматической отправки. Оператор должен ограничивать доступ к базе, проверять доступы, защищать резервные копии и удалять данные по достижении цели обработки или по иным предусмотренным законом основаниям. Эти меры и фактический порядок хранения подлежат проверке до включения формы.

9. Права посетителя

Вы можете запросить сведения об обработке ваших данных, потребовать их уточнения, блокирования или удаления при наличии оснований, а также отозвать согласие или потребовать прекращения обработки. Обращение направляется на email оператора, указанный в политике. После отзыва обработка прекращается и данные удаляются в предусмотренном законом порядке, если нет другого законного основания для их обработки. Вы вправе обратиться в уполномоченный орган или суд для защиты своих прав.

10. Трансграничная передача

Форма заявки на этом сайте сейчас отключена. До её включения оператор должен проверить фактическую схему передачи и хранения данных, включая поставщиков инфраструктуры, и при необходимости выполнить предусмотренные законом действия для трансграничной передачи. Наличие страницы на GitHub Pages само по себе не подтверждает, что данные будущих заявок будут передаваться через эту платформу.

11. Конфиденциальность

Доступ к данным заявки должен предоставляться только лицам, которым он необходим для ответа на обращение и выполнения ремонта. Раскрытие или публикация данных без соответствующего основания не предусмотрены. Фактический круг лиц с доступом и меры защиты оператор подтверждает до начала приёма заявок.

12. Заключительные положения и обновления
